# Smart Helmet System 🪖 - IoT Safety Project

## Overview
IoT-based smart helmet ensuring rider safety through helmet wear detection, alcohol detection & accident alert.

## Features
- Helmet Wear Detection (MPU6050)
- Alcohol Detection (MQ3 Sensor)
- Accident Alert via SIM800L GSM
- Bike Ignition Interlock
- Custom 2-Layer PCB in KiCad

## Tech Stack
- Microcontroller: ESP32
- Sensors: MPU6050, MQ3
- Communication: GSM, WiFi, Bluetooth
- Tools: KiCad, Arduino IDE, Embedded C
- Protocols: UART, I2C, SPI

## PCB Design
Designed in KiCad, DRC Checked, Gerber Generated
